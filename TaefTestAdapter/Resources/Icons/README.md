# Icons

The images in this folder (and the logo files `taef-logo.ico`/`taef-logo.png`, `Preview.png` and the
template icons `ItemTemplates\Test\TAEF\Icon.ico`, `ProjectTemplates\Test\TAEF\Icon.ico`) were created
for the Test Adapter for TAEF. They are generated by [`Tools\make_branding_assets.py`](../../../Tools/make_branding_assets.py)
(requires Pillow: `pip install pillow`); change the script and re-run it instead of editing the images by hand.

| File | Size | Used by |
|---|---|---|
| `Icon.ico` | 16, 24, 32, 48, 64, 128, 256 px | not used by any project (master copy of the template icon image, same image as `ItemTemplates\Test\TAEF\Icon.ico` and `ProjectTemplates\Test\TAEF\Icon.ico`); the package icon is `Packaging\Resources\taef-logo.ico`/`.png` and `VsPackage\Resources\taef-logo.ico` |
| `Icon_128.png` | 128 x 128 px | not used by any project (master copy of the template icon image as PNG, e.g. for documentation) |
| `toolbaricons.png` | 64 x 16 px (four 16 x 16 icons, transparent background) | toolbar of the VS package (`VsPackage\TaefTestAdapterPackage.vsct`) |

The order of the icons in `toolbaricons.png` must match the `usedList`/`IDSymbol` values of the `toolbaricons`
bitmap in `TaefTestAdapterPackage.vsct`:

1. *Run tests in process (/inproc)* - a process window with a "run" triangle
2. *Parallel test execution* - three parallel arrows
3. *Break on error* - a breakpoint with a failure cross and "pause" bars
4. *Print test output* - an output window with text lines

The toolbar icons use the Visual Studio Image Library color conventions (outline `#424242`, action blue
`#00539C`, action green `#388A34`, red `#E51400`) so that Visual Studio can adapt them to dark themes.
